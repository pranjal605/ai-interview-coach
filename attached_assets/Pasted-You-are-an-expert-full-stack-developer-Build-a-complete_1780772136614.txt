--- server/services/geminiService.js ---
Use the @google/generative-ai npm package.
Import { GoogleGenerativeAI } from "@google/generative-ai".
Create ONE instance: const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY).
Get the model once: const model = genAI.getGenerativeModel({ model: "gemini-1.5-flash" }).

Export three async functions:

1. generateQuestion(role, difficulty)
   Build this prompt string:
   "You are a strict technical interviewer. Generate ONE {difficulty} level interview question for a {role} candidate. Return ONLY a raw JSON object with NO markdown, NO code blocks, NO extra text. Exact format: { \"question\": \"...\", \"hint\": \"...\", \"expectedKeywords\": [\"keyword1\", \"keyword2\", \"keyword3\"] }"
   
   Call: const result = await model.generateContent(prompt)
   Get text: const text = result.response.text()
   Clean the response: strip any markdown code fences using:
     const cleaned = text.replace(/```json|```/g, "").trim()
   Parse with JSON.parse(cleaned) inside try/catch.
   Return the parsed object.

2. evaluateAnswer(question, answer, expectedKeywords)
   Build this prompt string:
   "You are an expert technical interviewer. Evaluate the candidate's answer strictly and fairly.
   Question: {question}
   Candidate's answer: {answer}
   Expected keywords: {expectedKeywords joined by comma}
   Return ONLY a raw JSON object with NO markdown, NO code blocks, NO extra text. Exact format: { \"score\": <integer 1-10>, \"strengths\": [\"...\", \"...\"], \"improvements\": [\"...\", \"...\"], \"modelAnswer\": \"...\", \"keywordCoverage\": <integer 0-100> }"
   
   Call model.generateContent(prompt), get text, strip markdown fences, parse JSON.
   Return parsed object.

3. parseJD(jdText)
   Build this prompt string:
   "Read this job description carefully and generate exactly 5 targeted interview questions a recruiter would ask. Job Description: {jdText}
   Return ONLY a raw JSON array with NO markdown, NO code blocks, NO extra text. Exact format: [{ \"question\": \"...\", \"hint\": \"...\", \"expectedKeywords\": [\"...\"] }, ...]"
   
   Call model.generateContent(prompt), get text, strip markdown fences, parse JSON array.
   Return parsed array.

IMPORTANT for all three functions:
- Always strip markdown using: text.replace(/```json|```/g, "").trim()
- Always wrap JSON.parse in try/catch. On catch, log the raw text and throw new Error("Gemini returned invalid JSON")
- Never return raw text — always return parsed JavaScript objects/arrays.

--- server/routes/question.js ---
POST /api/question
Body: { role, difficulty }
Validate both fields exist, return 400 if missing.
Call geminiService.generateQuestion(role, difficulty).
Return the question object as JSON.

--- server/routes/evaluate.js ---
POST /api/evaluate
Body: { question, answer, expectedKeywords, sessionId, questionIndex }
Call geminiService.evaluateAnswer(question, answer, expectedKeywords).
Find session by sessionId and push the answer, score, and feedback into MongoDB arrays.
Return feedback JSON.

--- server/routes/session.js ---
POST /api/session/start
Body: { role, difficulty }
Generate sessionId: `session_${Date.now()}_${Math.random().toString(36).substr(2,9)}`
Create and save new Session document.
Return { sessionId }.

GET /api/session/:sessionId
Find session by sessionId. Return full session document as JSON.

--- server/routes/jd.js ---
POST /api/jd/questions
Body: { jdText }
Validate jdText exists and length >= 50 characters. Return 400 if not.
Call geminiService.parseJD(jdText).
Return questions array as JSON.

--- server/middleware/errorHandler.js ---
Standard Express error middleware (4 args: err, req, res, next).
Log err.message to console.
Return res.status(500).json({ error: err.message }).

--- server/server.js ---
Import express, cors, dotenv/config.
Import and call db connection from config/db.js.

--- client/src/hooks/useVoice.js ---
Detect: const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition
If not available, return { supported: false } and stub functions.
Create recognition instance. Set continuous: false, interimResults: true, lang: "en-US".
State: transcript (string), listening (boolean).
startListening(): reset transcript, call recognition.start(), set listening true.
stopListening(): call recognition.stop().
resetTranscript(): set transcript to "".
recognition.onresult: concatenate e.results[i][0].transcript for all results, set transcript state.
recognition.onend: set listening to false.
Return { transcript, listening, startListening, stopListening, resetTranscript, supported: true }.

--- client/src/hooks/useInterview.js ---
Custom hook. Accepts { role, difficulty, totalQuestions }.
Internal state: questions[], answers[], feedbackList[], scores[], currentIndex (0), sessionId (""), phase ("idle").
Phases: "idle" → "loading" → "question" → "evaluating" → "feedback" → "summary"

startSession():
  Set phase to "loading".
  Call api.startSession(role, difficulty), store sessionId.
  Call api.getQuestion(role, difficulty), store in questions[0].
  Set phase to "question".

submitAnswer(answerText):
  Set phase to "evaluating".
  Call api.evaluateAnswer({ question: questions[currentIndex].question, answer: answerText, expectedKeywords: questions[currentIndex].expectedKeywords, sessionId, questionIndex: currentIndex }).
  Push feedback to feedbackList, score to scores, answer to answers.
  Set phase to "feedback".

nextQuestion():
  If currentIndex + 1 >= totalQuestions: set phase to "summary" and return.
  Set phase to "loading".
  Call api.getQuestion(role, difficulty), push to questions array.
  Increment currentIndex.
  Set phase to "question".

restartSession(): reset all state to initial values, set phase to "idle".

Return all state values and all four functions.

# AI Interview Coach

AI-powered mock interview platform built with React, Node.js, and Google Gemini API.

## Features
- Role-specific AI-generated questions (SDE, Data Analyst, PM, and more)
- Real-time AI feedback: score, strengths, improvements, model answer
- Voice input via Web Speech API (no extra library)
- Job Description parser — paste any JD to get tailored questions
- Session history with score trend chart

## Getting your Gemini API key
1. Go to https://aistudio.google.com/app/apikey
2. Click "Create API Key"
3. Copy it into server/.env as GEMINI_API_KEY

## Setup

### Backend
cd server
npm install
cp .env.example .env
# Fill GEMINI_API_KEY and MONGO_URI in .env
npm run dev

### Frontend
cd client
npm install
npm start

## Tech Stack
- Frontend: React.js, React Router v6, Axios, Recharts
- Backend: Node.js, Express, MongoDB Atlas, Mongoose
- AI: Google Gemini API (gemini-1.5-flash) via @google/generative-ai
